curl / Development / feature window

The feature window is now

While the feature window is open, we allow merging new features and changes. Normally, the feature window is open from the Saturday ten days following a release until the Saturday three weeks later, just over three weeks before the next pending release.

While the feature window is closed, we do not allow merging new features or changes and only merge bug-fixes.

You can still submit pull-requests for new features when the window is closed, but they will not be merged until the window opens again.
