curl-config is our friend

Applications (or actually whoever) that want to find out about the libcurl installation on a particular host, will find a friend in the curl-config tool.

What compiler flags do I need to compile libcurl using source code? 

 curl-config --cflags

What linker options do I need when I link with libcurl? 

 curl-config --libs

How do I know if libcurl was built with SSL support? 

 curl-config --feature | grep SSL

What's the installed libcurl version? 

 curl-config --version
